INTERVIEW QUEST V3 — PHONE UPLOAD

1. Download and extract Interview-Quest-v3.zip on your phone.
2. Open your GitHub repository in a browser.
3. Upload the CONTENTS of the extracted folder into the repository ROOT (main branch); do not create an extra nested folder.
4. Replace the existing app files with the V3 files:
   index.html, style.css, app.js, question-bank.js, sw.js, manifest.webmanifest, icon.svg, README.md, TEST-REPORT.md, validate-question-bank.js, smoke-test.js.
5. Open Settings -> Pages. Source should be branch main and folder /(root).
6. Wait until GitHub Pages reports the deployment is complete, then open the published site.
7. If you still see the old bank, close the installed PWA, fully reload the browser tab and clear site data only if necessary.

FREE/NO-KEY NOTE: The static app and all local features do not need a paid backend or OpenAI API key. The Ask ChatGPT shortcut opens the official ChatGPT website. It is not an embedded chat, and prompt prefilling depends on browser/site behavior.

VALIDATION: Run `node validate-question-bank.js`, `node smoke-test.js` and `node --check app.js` / `node --check question-bank.js` / `node --check sw.js` when Node.js is available.
