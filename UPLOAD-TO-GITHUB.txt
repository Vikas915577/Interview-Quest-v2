INTERVIEW QUEST V3.1 — UPLOAD FROM PHONE

1. Download and extract Interview-Quest-v3.1.zip.
2. Open your GitHub repository in a browser and choose Add file -> Upload files.
3. Upload the extracted FOLDER CONTENTS to the repository ROOT (main branch), not as a nested folder.
4. Replace the existing app files. IMPORTANT: upload sql-lab.js too.
5. Commit changes to main.
6. Open Settings -> Pages and confirm source is branch main, folder /(root).
7. Open the live site after deployment and verify the Questions page says 500 and Practice -> SQL Practice shows sample tables plus 20 exercises.
8. If the old version remains, close any installed PWA, hard-refresh, and check that the browser is using the new deployed files.

This is a free static app; no API key is required for its core features. SQL examples are study prompts and are not executed in the browser. ChatGPT opens separately.

Run checks when Node.js is available:
node validate-question-bank.js
node smoke-test.js
node --check app.js
node --check question-bank.js
node --check sql-lab.js
node --check sw.js
